# Élan Convention House — Cinematic Prototype

Open `index.html` in a modern browser. Internet access is recommended because some placeholder reference images are loaded from public image URLs. The exterior establishing image is bundled locally.

## What is implemented

- 760vh cinematic scroll timeline
- Opening visual hold / breathing room
- Slow exterior dolly and depth illusion
- Intentional pause before the second movement
- Entrance alignment and stronger approach
- Entrance-to-lobby crossfade / threshold transition
- Grand hall reveal with visual hold
- Stage focus and transition into normal site content
- Scene progress rail and contextual captions
- Luxury editorial typography and restrained overlays
- Spaces, occasions, gallery, facilities, location and enquiry sections
- Interactive event-type tabs
- Responsive mobile layout
- `prefers-reduced-motion` fallback
- Prototype enquiry form feedback

## Production upgrade path

Replace the CSS camera illusion with React Three Fiber / Three.js scenes and a camera spline. Keep the same storyboard and progress bands so that the interaction rhythm remains unchanged while geometry, depth, lighting and camera target become physically accurate.
